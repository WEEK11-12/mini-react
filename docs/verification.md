# 검증 문서 이동 안내

기존 검증 계획은 [테스트 전략과 검증 근거](testing.md)로 옮겼습니다. V-01~V-12 식별자는 유지하고 이벤트·브라우저·실패 검증을 확장했습니다.

- [테스트 전략](testing.md): 수준별 책임, 요구사항 대응, 실제 결과 기록 양식.
- [요구사항](requirements.md): 기능·품질·불변조건.
- [API 계약](api-contracts.md): 테스트가 확인할 동작 초안.

현재 테스트 도구·실행 명령·통과 결과는 없습니다. 문서 구조 검사와 제품 기능 테스트는 구분합니다.
