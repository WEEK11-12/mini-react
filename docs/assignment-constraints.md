# 외부 과제 제약과 대응표

대화로 제공된 「AI 함께하기 / 미니 리액트 구현」 안내를 설계와 연결합니다. 라이브러리의 필요성은 [문제 정의](problem-definition.md)에서 출발합니다.

## 1. 확인된 조건

- 원본은 HTML·CSS·Vanilla JavaScript 또는 TypeScript를 명시하며 외부 UI 프레임워크를 금지합니다.
- 팀은 Python을 선택했습니다. 예외 허용 여부는 확인되지 않았습니다.
- 루트만 State·Hook을 사용하고 자식은 props 기반 순수 함수여야 합니다. 실제 React 전체의 일반 규칙은 아닙니다.
- FunctionComponent 클래스, hooks 배열, mount·update, 세 Hook을 직접 구현해야 합니다.
- Phase 2는 Phase 1의 Virtual DOM·Diff·Patch를 재사용해야 합니다.
- 전체 2주에 Redis·DBMS도 포함됩니다. 미니 React만의 확정 일정은 없습니다.

## 4. 선택 기능

Batching은 선택 과제입니다. 키 기반 재정렬·자식별 Hook·변경 시각화 등은 확장 후보이며 현재 완료 조건이 아닙니다. 필수 기능의 정확성 검증 후 채택 여부를 결정합니다.
