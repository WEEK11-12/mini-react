# AI 협업 절차 — 명세에서 검증까지

상태: 이 저장소에서 제안하는 협업 방식. 특정 AIDD 도구나 모든 프로젝트가 따라야 할 보편 표준을 뜻하지 않습니다. 짧은 실행 지침은 [AGENTS.md](../AGENTS.md)에 둡니다.

## 1. 문서가 맡는 역할

- README: 사람에게 목적·상태·실행·문서 경로를 안내.
- AGENTS.md: AI에게 작업 규칙과 읽을 문서를 안내.
- 요구사항·API: 무엇을 구현하고 어떤 동작을 지킬지 정의.
- ADR: 선택 이유와 비용을 보존.
- 테스트·실행 기록: 계약 충족의 근거.
- 학습 기록: 개인의 이해와 기여를 제품 명세와 분리.

문서 양을 늘리는 것 자체가 목적은 아닙니다. 작업자가 중요한 판단을 추측하지 않게 하고, 변경 시 함께 고칠 수 있는 크기로 유지합니다.

## 2. 책임

| 역할 | 책임 |
| --- | --- |
| 사용자·팀 | 목표·외부 제약·중요한 설계 선택 확인, 핵심 흐름 재설명 |
| 구현 AI | 관련 문서·코드 확인, 작은 구현·테스트·설명, 미확정 사항 공개 |
| 리뷰어 | 계약 누락·실패 경로·증거 검토. 가능하면 구현자와 별도 관점 |
| 실행 도구 | 실제 명령·브라우저 결과 제공. AI 설명은 실행 증거를 대체하지 않음 |

## 3. 작업 한 단위

~~~text
문제·FR 선택
 → 관련 C·ADR 읽기
 → 예상 동작과 경계 테스트 정의
 → 작은 구현
 → 단위·통합·필요 시 브라우저 검증
 → 사용자 설명·질문
 → 문서·근거 갱신
~~~

매 단계에서 허락을 반복 요청하지 않습니다. 이미 요청된 안전한 수정·검증은 진행하고, 미확정 구조에 의존하거나 파괴적인 선택만 질문합니다. 모르는 기술을 조용히 가정하지 않습니다.

## 4. 작업 요청 양식

~~~text
목표: 해결할 사용자 문제
요구사항: FR-*, NFR-*
계약·결정: C-*, ADR-*
현재 상태: 소스·테스트·직전 실행 근거
범위: 변경할 책임과 이번에 다루지 않을 것
완료 조건: 입력·행동·관찰 결과
검증: 테스트/브라우저 시나리오, 실제 명령은 존재하는 것만
미확정: 질문 또는 초안 채택이 필요한 지점
학습 질문: 사용자가 예측·설명할 핵심 한 가지
~~~

예: "FR-04의 동일 트리 Diff를 구현한다. C-04와 ADR-0003을 확인하고 입력 불변·빈 변경 목록을 테스트한다. DOM adapter와 History는 수정하지 않는다." 이 예는 현재 알고리즘 초안을 채택한 뒤 사용할 요청입니다.

## 5. 단계별 진입·종료 조건

| 단계 | 들어가기 전 | 산출물·종료 기준 |
| --- | --- | --- |
| G0 문제·문서 검토 | 제공 목표·현 저장소 확인 | P→FR→C→V 연결, 초안·미정 표시 |
| G1 실행 구조 실험 | Python 허용·도구 범위 확인 | ADR-0002 실험 근거와 채택·기각 기록 |
| G2 트리·Diff·Patch | 관련 데이터·경로 계약 채택 | FR-01~05 단위·실제 DOM 검증 |
| G3 편집·History | 편집 방식·복구 계약 채택 | FR-12~13, 양쪽 영역·분기·실패 검증 |
| G4 루트·State | Hook 문맥·갱신 API 채택 | FR-06~08, 재실행·수명·DOM 연결 |
| G5 Effect·Memo | 비교·오류·정리 계약 채택 | FR-09~11, deps·정리·브리지 검증 |
| G6 재현·포트폴리오 | 실제 기능·검증 근거 확보 | 실행 안내·데모·한계·기여 근거 연결 |

이 표는 구현 순서의 초안이며 날짜·팀 역할을 확정하지 않습니다. 단계 통과는 결과 근거로 판단합니다.

## 6. 완료 보고·인수인계

~~~text
변경: 파일·요구사항 ID
선택 이유: 관련 ADR 또는 이번 결정
검증: 실행한 명령·환경·실제 결과
학습: 핵심 흐름과 사용자 확인 여부
남은 점: 실패·미실행·초안·외부 확인
다음 작업: 필요한 문서·파일·조건
작업 상태: 관련 커밋 또는 미커밋 변경
~~~

대화 기억에 의존해 다음 AI에게 맡기지 않습니다. 새 작업자는 실제 git 상태와 문서를 다시 확인합니다. 관련 문서만 연결하고 비밀 정보·원문 대화 전체를 복사하지 않습니다.
