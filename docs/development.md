# 개발 명세 문서 이동 안내

기존 통합 개발 명세는 책임별 문서로 분리했습니다. 이 파일은 기존 링크를 위한 진입점이며 별도의 동작 계약을 정의하지 않습니다.

1. [문제 정의](problem-definition.md): 해결할 문제와 비목표.
2. [요구사항](requirements.md): 외부에서 관찰할 동작.
3. [아키텍처](architecture.md): 책임·소유권·실행·실패 경로.
4. [API 계약](api-contracts.md): 데이터·입출력·오류·수명 초안.
5. [설계 결정](decisions/README.md): 언어·실행 구조·알고리즘 선택 이유.
6. [AI 협업 절차](ai-workflow.md): 구현 단위·검토·인수인계.

현재 구현 전이며 새 API·구조는 팀 채택 전 초안입니다. 상세 상태는 [문서 지도](README.md)를 따릅니다.
