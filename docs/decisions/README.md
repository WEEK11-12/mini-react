# Architecture Decision Records

ADR은 구조·인터페이스·의존성·품질에 영향을 주는 **선택 하나의 이유와 결과**를 기록합니다. 문서 양식은 Michael Nygard의 [원문](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)을 참고하며, 경로와 검증 항목은 이 프로젝트에 맞게 조정했습니다.

## 작성·변경 규칙

- 제안·채택·기각·대체됨을 구분합니다. AI가 제안한 결정을 팀 합의로 기록하지 않습니다.
- 중요한 선택만 작성합니다. 파일명·작은 지역 변수마다 ADR을 만들지 않습니다.
- 결정을 뒤집으면 기존 기록을 삭제하지 않고 대체 ADR을 연결합니다.
- 채택·검증·성능 측정은 서로 다른 상태입니다.
- 결정이 API·요구사항과 충돌하면 관련 문서를 같은 변경에서 갱신합니다.
