# ADR-0001: 핵심 로직의 구현 언어로 Python 선택

- 상태: 팀의 언어 선택 기록. 과제 허용 여부는 미확인.
- 기록일: 2026-11-06.
- 결정 주체: 사용자 설명에 따른 팀 결정.
- 관련: O-01, O-02, NFR-03, NFR-06.

## 맥락

팀 공통 언어는 C와 Python입니다. 사용자는 DOM·React 기초부터 이해하고 싶으며 AI가 코드를 주로 작성하더라도 이유와 원리를 설명할 수 있기를 원합니다. 새로운 언어까지 동시에 배우는 비용을 고려해야 합니다.

## 대안

| 대안 | 이점 | 비용 |
| --- | --- | --- |
| C | 공통 언어, 메모리 동작을 직접 관리 | 트리·문자열·메모리 관리와 브라우저 연결 부담 |
| Python | 공통 언어, 자료구조·함수 표현과 테스트에 집중 | 브라우저 실행 환경 또는 연결 계층 필요 |
| JavaScript/TypeScript | 원본 기술 조건 충족, 브라우저 경계가 단순 | 팀의 언어·타입·도구 학습 비용 |

## 결정과 이유의 구분

실제로 확인된 선택 이유는 **팀 공통 언어이기 때문**입니다. 자료구조 표현과 메모리 관리 부담을 줄여 UI 갱신에 집중할 수 있다는 설명은 이 선택을 검토한 AI의 추가 근거이며, 팀이 이미 비교·검증한 결과로 기록하지 않습니다.

Python을 선택하되 브라우저 실행 구조는 별도의 ADR-0002로 결정합니다.

## 결과와 한계

- 팀이 서로 읽고 검토할 수 있는 언어를 사용합니다.
- Python 선택만으로 DOM 접근이 해결되지는 않습니다.
- 비교 연산·함수 identity·객체 수명은 JavaScript와 다르므로 별도 API 계약이 필요합니다.
- 원본 과제의 JavaScript/TypeScript 제한을 충족한다고 단정할 수 없습니다.

## 검증과 재검토

언어 비교 벤치마크·실행 실험은 아직 없습니다. O-01이 부정적이거나 브리지 비용이 핵심 학습을 압도하면 재검토합니다. Python이 React 구현에 보편적으로 최적이라는 주장을 하지 않습니다.
